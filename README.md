# Video Templates Android App

This project contains a simple Android app for showing 120+ original video template ideas.

## Features
- Search templates
- Filter by category
- Copy template text to clipboard
- Clean Material design

## Run in Android Studio
1. Open Android Studio
2. Select "Open an existing project"
3. Open this folder
4. Let Gradle sync
5. Run on emulator or device

You can download the whole project as a ZIP from the GitHub repository page.
